## v1.3.6 · 2026-11-13

- Tag：`v1.3.6`
- 安装包：`KanFanOS_1.3.6_x64-setup.exe`（171.96 MiB，180,310,717 字节）

### 播放器控制栏
- 窗口模式控制栏改为可换行布局：窄分辨率下，右侧倍速/音轨/音频输出/字幕/全屏整组换到下一行并保持右对齐，全屏按钮不再被挤出屏幕

### 集数解析
- 集数完整性分析改为「同一集且同一版本」才算重复：`06` 与 `06v2` 是同一集的新旧发布，不再误报重复
- 修复标题里的季号被当成集数：`Season 2 - 24` 现在解析为第 24 集，不会再让 13–24 集全部变成第 2 集并互相重复
- 标题带 ` - ` 分隔符时优先取分隔符之后的数字：`冰劍的魔術師將要統一世界 2 - 06`、`Black Clover 2nd Season - 176` 都能得到正确集数
- `720P`、`480P` 这类大写分辨率标记不再被当成集数

### 安装包
- Windows x64 NSIS 安装包
- 文件大小：171.96 MiB（180,310,717 字节）
- SHA256：`95208E76D3E02FEB278B9200079B96B7588DD77773B82F4BFC2EA219EF72E9EF`

## v1.3.0 · 2026-10-27

- Tag：`v1.3.0`
- 安装包：`KanFanOS_1.3.0_x64-setup.exe`（171.82 MiB，180,169,044 字节）

#### RSS 追番

- 新增侧栏「追番」页：RSS 源、追番订阅、最近匹配
- RSS 由应用负责抓取，qBittorrent 只负责下载
- 自动下载只补每个追番的最新一集，默认关闭自动下载
- 支持限定字幕组和字幕封装方式；自动下载必须同时满足，最近匹配仍显示其它版本供手动下载

- `.torrent` 由应用先用系统代理抓取，再以文件方式上传给 qBittorrent；qBittorrent 可以不配代理
- 资源页任务列表现在包含当前下载目录下的子目录任务
- 最近匹配只显示选中的追番，支持多选过滤

#### 浏览器

- 内嵌浏览器选中文字后右键「以当前文字添加追番」
- 自动解析字幕组、番名候选、集数、分辨率、字幕语言、字幕封装、来源、版本等字段并预填添加追番弹窗
- 子 WebView IPC 不可用时自动走导航代理兜底

#### 字幕
- 外挂 SRT/VTT/ASS/SSA 统一识别 UTF-8 / UTF-16 / GB18030 后转 UTF-8 缓存加载，修复 GBK 字幕乱码
- 外挂字幕轨道保留原文件名，不再显示缓存哈希名
- 字幕菜单支持整体提前 / 延后 0.1 秒和复位，切轨道不收起面板

#### 播放器
- 单击画面或上下黑边只收起控制栏，不再切换播放 / 暂停
- 空格播放/暂停不会重新唤出控制栏
- 新增音轨切换
- 全屏控制栏、字幕/音轨面板与原生视频窗口的 FLIP 同步

#### 番剧与最近观看
- 详情页支持全部标记已看完、清除观看记录、手动「看过 N 遍」
- 最近观看按番剧去重，点击进入选集页并自动续播上次位置
- 番剧卡片无封面时使用首字占位

#### 设置
- 新增 Windows 开机自启动（HKCU Run）
- 版本号 0.1.1

安装包：`KanFanOS_0.1.1_x64-setup.exe`
